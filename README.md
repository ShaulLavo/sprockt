# Sprockt

Free, MIT-licensed browser IDE that runs real Bun in WebAssembly across Chrome, Firefox, desktop Safari and iPhone Safari.

## Open a GitHub repo

```text
https://sprockt.dev/github/<owner>/<repo>
```

## Run locally

```sh
bun install
bun run guests
bun run dev
```

## Engines

[bun-wasm](https://github.com/ShaulLavo/bun-wasm) · [Waffle](https://github.com/ShaulLavo/waffle) · [Singapore](https://github.com/ShaulLavo/singapore) · [ghostty-webgpu](https://github.com/ShaulLavo/ghostty-webgpu) · [bash-web](https://github.com/ShaulLavo/bash-web)
