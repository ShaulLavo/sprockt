# Sprockt

Open-source browser IDE powered by [bun-wasm](https://github.com/ShaulLavo/bun-wasm), [Waffle](https://github.com/ShaulLavo/waffle), [Singapore](https://github.com/ShaulLavo/singapore), [ghostty-webgpu](https://github.com/ShaulLavo/ghostty-webgpu), and [bash-web](https://github.com/ShaulLavo/bash-web).

Run it with `bun install && bun run guests && bun run dev`; the design is in [ARCHITECTURE.md](ARCHITECTURE.md).
